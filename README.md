# Проекты по RPA

- [ДомТорг](domtorg/README.md) – категоризация товаров по ТЗ Киц-Ковязина.
- [ОфисСнаб](rpa_course/README.md) – расчёт стоимости заказа по ТЗ Затопляева.

Для «ОфисСнаб» доступны [запуск через Docker Compose](rpa_course/README.md#запуск-через-docker) и [сценарий демонстрации](rpa_course/DEMO.md).

Демонстрационные архивы хранятся локально в `artifacts/`, ТЗ – в папках `docs/` соответствующих проектов, шаблон и материалы Яшина – в `materials/`. В папках `_work` хранятся черновики и вспомогательные файлы. Эти папки исключены из Git.
