# RPA-робот «ОфисСнаб»

Робот принимает заказы по почте, рассчитывает стоимость по Excel-прайсу и отправляет коммерческое предложение или запрос на уточнение. Код, настройки и файлы запуска находятся в `rpa_course/`.

- [План реализации](rpa_course/PLAN.md)
