# План реализации RPA-робота «ОфисСнаб»

Робот принимает запросы из Яндекс Почты, сопоставляет товары с Excel-прайсом и отправляет коммерческое предложение или просьбу об уточнении. Работаем в ветке `dev`, сообщения коммитов пишем по-русски.

## 1. Основа проекта и прайс-лист

- [x] Подготовить ручной запуск на Python, конфигурацию и базу SQLite для состояний обращений.
- [x] Загружать и проверять `data/price.xlsx`. Сохранять снимок и контрольную сумму прайса на цикл, при ошибке останавливать цикл.

## 2. Приём обращений

- [x] Подключить Яндекс Почту по IMAP. При первом запуске зафиксировать границу старых писем, затем отбирать новые запросы, в теме которых есть «Расчёт заказа» или «Расчет заказа».
- [x] Извлекать текст из обычных и HTML-писем, определять адрес ответа и защищать обращения от повторной обработки.
- [ ] Проверить приём на настроенном учебном ящике Яндекс Почты.

## 3. Сопоставление товаров и расчёт

- [x] Подключить GigaChat API (`GigaChat-2-Pro`) через OAuth и проверять TLS-сертификаты.
- [x] Проверять структуру ответа модели, артикулы, количество и единицы измерения. Для неоднозначного или неполного запроса сохранять причины уточнения.
- [x] Объединять одинаковые позиции и рассчитывать итог по сохранённому прайсу с помощью `Decimal`.
- [ ] Проверить расчёт на вымышленном заказе через реальный GigaChat API.

## 4. Формирование и отправка ответа

- [x] Подготовить шаблоны КП и уточнения в HTML и обычном тексте. Присваивать КП номер, указывать срок действия и сохранять копию ответа до отправки.
- [x] Отправлять ответ по SMTP в исходной цепочке и сохранять статус. При неизвестном результате отправки передавать обращение сотруднику без автоматического повтора.
- [ ] Проверить отправку на учебном ящике Яндекс Почты.

## 5. Запуск и сопровождение

- [ ] Настроить запуск каждые пять минут с 09:00 до 18:00 по Иркутску через Планировщик заданий Windows. Блокировать параллельные запуски.
- [ ] Хранить пароль почты и ключ API в диспетчере учётных данных Windows. Вести технический журнал и уведомлять сотрудника об ошибках и обращениях, требующих проверки.

## 6. Испытания и сдача

- [ ] Проверить расчёт **2 790,00 ₽** для примера из ТЗ, отправку КП и запрос уточнения при неоднозначном товаре.
- [ ] Проверить сбои прайса, почты и модели, повторный запуск и восстановление после обрыва отправки.
- [ ] Проверить нагрузку и время обработки по ТЗ. Подготовить инструкцию запуска и протокол испытаний.

## 7. Панель сотрудника — дополнительный этап

- [ ] Сделать журнал обращений с фильтрами по дате и статусу и быстрым доступом к обращениям, требующим проверки.
- [ ] Добавить карточку обращения с этапами обработки, причиной ошибки, версией прайса и сохранённым ответом.
