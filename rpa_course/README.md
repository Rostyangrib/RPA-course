# RPA-course

RPA-робот «ОфисСнаб» для расчёта стоимости заказа.

## Запуск через Docker

1. Запустите Docker Desktop. Из корня репозитория откройте локальные настройки в PowerShell.

   ```powershell
   if (-not (Test-Path .env)) { Copy-Item .env.example .env }
   notepad .env
   ```

2. Заполните файл `.env` и сохраните его. В Docker адрес ящика читается из `RPA_MAIL_ADDRESS`. Для стандартного запуска пути к Excel, SQLite и сертификату уже заданы в `rpa_course/config.toml`.

   | Настройка | Что указать |
   | --- | --- |
   | `RPA_MAIL_ADDRESS` | Полный адрес учебного ящика Яндекс Почты, который принимает заявки и отправляет ответы |
   | `RPA_MAIL_PASSWORD` | Пароль приложения типа «Почта» **от ящика робота**. Включите IMAP в настройках этого ящика |
   | `GIGACHAT_CREDENTIALS` | Ключ авторизации GigaChat без префикса `Basic` |
   | `RPA_NOTIFY_TO` | Адрес сотрудника для уведомлений. Поле можно оставить пустым |

   Адрес покупателя используется только для отправки письма. Ответ придёт на его `Reply-To` или адрес отправителя. Пароль покупателя роботу не нужен. Пароль приложения и ключ вставьте между кавычками в локальном `.env`. Этот файл исключён из Git.

3. Соберите и запустите контейнер.

   ```powershell
   docker compose up --build -d
   ```

   Откройте [веб-панель](http://127.0.0.1:8765/). Если порт занят, задайте `RPA_PORT` в `.env` и откройте новый порт. Для проверки используйте [сценарий демонстрации](DEMO.md).

Обращения, копии ответов и технический журнал сохраняются в томе `ofissnab_state`. `docker compose down` останавливает панель и сохраняет том. Прайс `rpa_course/data/price.xlsx` подключён из рабочей папки для чтения.

## Ручной запуск

Выполняйте команды в PowerShell из корня репозитория `RPA_course`. Нужен Python 3.11 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r rpa_course/requirements.txt
.\.venv\Scripts\python.exe -m rpa_course
```

Команда проверяет `rpa_course/data/price.xlsx`, сохраняет его снимок в `rpa_course/.runtime/state.sqlite3` и выводит число товаров и SHA-256. При ошибке цикл завершается с кодом `1` и объяснением в стандартном потоке ошибок.

Пути задаются в [config.toml](config.toml). Чтобы выбрать другой файл, передайте `--config путь.toml`. Относительные пути внутри TOML считаются от папки этого файла.

## Подключение учебного ящика Яндекс Почты

1. Включите IMAP и пароли приложений в настройках учебного ящика. Создайте пароль приложения для почты. [Настройки почтовых клиентов Яндекса](https://yandex.ru/support/yandex-360/customers/mail/ru/mail-clients/mail-clients-troubleshooting.html)
2. Укажите адрес ящика в `mail.address` в `config.toml`.
3. Сохраните пароль приложения в диспетчере учётных данных Windows. Подставьте тот же адрес в команду, пароль введите по запросу.

   ```powershell
   .\.venv\Scripts\python.exe -m keyring -b keyring.backends.Windows.WinVaultKeyring set RPA-course ИМЯ@yandex.ru
   ```

4. Запустите робота. Первый запуск запомнит границу существующих писем. Отправьте на учебный ящик письмо с темой «Расчёт заказа» после этого запуска и запустите робота ещё раз.

Для ящиков `@yandex.ru` робот берёт логин из части адреса до `@`. В `mail.address` и в команде сохранения пароля указывайте полный адрес. [Инструкция Яндекса](https://yandex.ru/support/yandex-360/customers/mail/ru/mail-clients/others)

Результат приёма сохраняется в SQLite. Письма читаются без отметки «Прочитано». Пустое значение `mail.address` оставляет доступной проверку прайса без подключения к почте.

## Сопоставление товаров через GigaChat

В `config.toml` заданы модель `GigaChat-2-Pro`, область доступа `GIGACHAT_API_PERS`, URL API и путь к PEM-файлу. Клиент использует проверку TLS. [Справка по сертификатам](https://developers.sber.ru/docs/ru/gigachat/certificates)

Сохраните ключ авторизации без префикса `Basic` в диспетчере учётных данных Windows. Вставьте ключ по запросу команды.

```powershell
.\.venv\Scripts\python.exe -m keyring -b keyring.backends.Windows.WinVaultKeyring set RPA-course GIGACHAT_CREDENTIALS
```

Проверить GigaChat на вымышленном заказе из ТЗ можно отдельно от почты. Для учебного прайса ожидаемый итог — `2790.00`.

```powershell
.\.venv\Scripts\python.exe -m rpa_course --check-gigachat
```

Если системный прокси задерживает запросы к GigaChat, перед запуском задайте исключение для двух адресов сервиса. Оно действует в текущем окне PowerShell и запущенных из него процессах.

```powershell
$env:NO_PROXY = 'api.giga.chat,ngw.devices.sberbank.ru'
```

При обычном запуске робот анализирует зарегистрированные обращения и сохраняет расчёт или причины уточнения в `order_analyses` вместе с контрольной суммой прайса. В GigaChat передаются текст запроса и характеристики товаров. Цены робот берёт из Excel, суммы рассчитывает локально.

Перед вызовом GigaChat робот локально проверяет язык запроса и присваивает ID выделенным позициям. При пропуске позиции модель получает один повтор. Если текст нельзя уверенно разделить на позиции, робот просит перечислить товары по одному на строку.

## Технический журнал и уведомления

В `rpa_course/.runtime/technical.sqlite3` хранятся время события в UTC, ID обращения, этап, статус и код ошибки. При запуске удаляются записи старше 30 дней.

Чтобы включить уведомления, задайте два адреса в PowerShell перед запуском робота или веб-панели:

```powershell
$env:RPA_NOTIFY_FROM = 'robot@yandex.ru'
$env:RPA_NOTIFY_TO = 'employee@example.com'
```

Подставьте адрес учебного ящика из диспетчера учётных данных Windows и адрес ответственного сотрудника. Отдельные переменные позволяют уведомить сотрудника и при ошибке чтения TOML. За цикл отправляется одно сводное письмо при ошибках или обращениях на проверку. Сбой SMTP фиксируется в техническом журнале.

## Ответы клиентам

После расчёта робот отправляет КП или письмо-уточнение через `smtp.yandex.ru:465` с TLS и тем же паролем приложения. Ответ отправляется одному адресату в исходной цепочке. КП нумеруются по иркутской дате и действуют пять календарных дней. [Параметры SMTP Яндекса](https://yandex.ru/support/yandex-360/customers/mail/ru/mail-clients/mail-clients-troubleshooting.html)

До отправки письмо сохраняется как `.eml` в папке `responses` рядом с базой состояний. В `responses` базы хранятся номер КП, дата, путь к копии и код ошибки. При неясном результате SMTP или прерванной отправке робот сохраняет статус `send_unconfirmed`. Сотрудник проверяет, был ли принят ответ, и при необходимости отвечает вручную. Обращения без корректного `Message-ID` помечаются для проверки.

### Где смотреть письма

В веб-версии Яндекс Почты откройте **Входящие** для полученных писем и **Отправленные** для писем, копии которых есть в ящике. В живом тесте Яндекс доставил письмо, переданное через SMTP, во **Входящие** без сохранения копии в **Отправленных**. [Папки Яндекс Почты](https://yandex.ru/support/yandex-360/customers/mail/ru/web/mailbox/folders)

Копии ответов робота по умолчанию находятся в `rpa_course/.runtime/responses/`. Файл `.eml` можно открыть в почтовой программе. Наличие копии означает, что ответ подготовлен. Подтверждение приёма сервером фиксируется статусом `sent` в таблице `requests` базы `rpa_course/.runtime/state.sqlite3`. Таблица `inbox_messages` хранит разобранные обращения.

Шаблоны HTML и обычного текста находятся в `rpa_course/templates`. Проверки с имитацией IMAP, GigaChat и SMTP запускаются командой `python -m unittest discover -s rpa_course/tests`.

## Веб-панель сотрудника

1. Из корня репозитория запустите `python -m rpa_course.web`.
2. Откройте [журнал обращений](http://127.0.0.1:8765/). Используйте поиск по теме, адресу или номеру КП, фильтры по дате и статусу.
3. Нажмите на тему письма, чтобы увидеть расчёт, ход обработки, причины уточнения или ошибки и скачать сохранённый ответ `.eml`.

На вкладке **Прайс-лист** отображается лист «Прайс» из Excel-файла, указанного в `paths.price_list`. Кнопка **Обновить** заново читает файл.

Для работы с почтой запускайте панель с конфигурацией, в которой указан `mail.address`, под тем же пользователем Windows, который сохранил пароль почты и ключ GigaChat.

```powershell
python -m rpa_course.web --config rpa_course/.runtime/mail.toml
```

Нажмите **Обработать почту**, чтобы запустить цикл робота. Он проверит новые письма, рассчитает заказы или подготовит уточнения и отправит ответы. После завершения журнал обновится, а итоги будут доступны в **Отчёте запуска**. Для просмотра базы испытаний используйте `--db путь-к-базе.sqlite3`. Панель доступна на этом компьютере. Сервер в терминале останавливается сочетанием `Ctrl+C`.
